## 工程约束

- 数据库新增 0002，不修改 0001；关键恢复和并发代码使用中文注释。
- 执行身份统一 ExecutionLease，提交与事件遵守同一租约和事务边界。
- 上传和仓库代码仅作为数据进入沙箱，不在宿主机执行。
- 模型只提建议；路径、依赖、预测、指标、证据和预算由代码校验。
- 未联网、未配置模型、缺少资产与资源不足明确报错或记录状态。
- Ruff、严格 mypy、行为测试、锁文件、打包和前端检查通过；Windows/Ubuntu 与 Python 3.12/3.13 的远程 CI 已实际运行成功。
- 原 Go 源码保持独立，React 工作台在 Python 目录维护自己的依赖和部署。

## 当前明确边界

当前不包含 GPU 训练、OCR、任意安装脚本、依赖源码编译、跨主机调度或公网账号体系。真实模型的小型生成、引用、抽取、修复与评估链已验收。小型运行成功和示例指标不代表完成任意论文的科学复现；模型科研质量、长文能力与原 Go HTTP 服务端尚未做完整外部验收。
