# 执行文件、图表和下载

独立 Python 代码节点可把结果写入 `/workspace/artifacts`。例如使用标准库创建 SVG，或在已具备对应依赖的环境中生成 PNG。程序运行成功后，系统在同一个容器内以独立解释器收集文件，再关闭容器。生成的程序始终在沙箱中运行。

每次最多收集 8 个文件；默认输出预算下总原始内容约 341 KiB，最多 1 MiB。超限、符号链接、设备、FIFO、过长路径和内容校验失败会使该任务明确失败。不会把未读取的文件登记为成功产物。

新增代码计划声明 `execution_files` 产物，保存 execution.files/v1 文件集合：相对路径、大小、SHA-256 和 base64 内容。旧计划保持原产物契约。`run_metrics` 继续保存实际 stdout/stderr/退出码。Data Agent 的统计与缺失值 SVG 分别保存为 data_profile 和 data_chart。

任务完成事件和持久状态包含首张图的预览；界面支持 PNG/JPEG/WebP/SVG，刷新后从后端恢复。预览通过 img 显示，不把 SVG 或 HTML 作为页面脚本执行。产物文件区提供单独下载，图表也可直接导出。

`GET /api/plans/{plan_id}/artifacts/{artifact_id}/files/{index}` 校验计划归属、文件集合摘要和文件内容摘要后返回附件。下载路由只接受已保存的产物与索引，不接收宿主机路径；响应包含附件文件名、内容类型和限制执行的 CSP。

这些产物证明实际代码输出了相应文件。图表内容或实验结论的科学有效性仍由数据、指标和证据验收判断。
