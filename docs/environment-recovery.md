# 科研环境准备与执行恢复

本功能覆盖标准科研计划与框架对比分支的初始解析、wheel 锁定、容器安装，以及执行阶段缺失模块恢复。支持有界依赖增补、版本调整及删除/替换；自动 Python 运行时选择和 GPU/full 仍待迁移。

## 初始准备

新自动设计节点输出 `dependency_resolution_report`，记录实际 uv 解析退出码、最多 16 KiB 的诊断及依赖提议。新环境节点输出 `environment_preparation_report`、`prepared_environment` 和 `environment_lock`；只有实际解析与来源校验成功后才交付后两者。失败只保存诊断，不伪造锁，也不启动科研程序。原始 `research_spec` / `experiment_design` 保留来源，后续统一读取实际的 `prepared_environment`，预检和正式运行继续核对实际锁摘要。

版本或平台不兼容、依赖闭包错误可在权限和预算内提出包增补/版本调整。哈希错误、包身份/下载来源不符及资源超限不能通过换包绕过；网络错误由下载器原有的有限重试处理。用户显式版本约束持续生效，矛盾的模型提议在采用前拒绝。每个准备节点最多 2 次修复，节点及计划时限仍生效；旧计划缺少新契约时不自动获得修复权限。

诊断模型收到实际错误，并可收到最多 4 个真实 PyPI 包版本的名称、版本、Python 要求、来源 URL 和原响应 SHA。来源获取有独立的 10 秒上限；查不到仅表示本次元数据不可用，不能宣称版本不存在。模型记忆不能代替来源。

新设计最多 32 个直接依赖请求；恢复入口允许保留已有最多 128 个包，每次模型提议最多 8 个变更，最终完整闭包仍不能超过 128。该入口不增加新设计请求预算。不会在宿主机导入或安装实验包，不执行源码构建与仓库安装脚本。

`remove_requirements` 明确列出待删除的既有直接请求；替换必须同时声明旧包删除与实际新包，新增、更新、删除合计最多 8 项。用户环境约束、原目标明确点名的库和框架主包不能被移除，同名包也不能在一次提议中同时删除和添加。误列的标准库安装请求在准备阶段直接诊断，`exit_code=null` 表示尚未运行解析进程；删除该安装请求不改变原程序使用标准库的目标。环境变更通过重新解析/锁定和新容器安装生效，不在旧容器就地卸载。每次采用的完整锁保存在恢复决策中，便于回放中间环境。

新框架设计阶段也保存独立命名空间的 `environment_preparation_report`。模型识别的版本可在预算内恢复，用户明确指定的版本范围持续生效；框架主包身份不可替换。来源 URL、版本、SHA 及 API 摘录均从恢复后实际采用的 wheel/元数据重新建立，报告显示实际准备次数、修复和历史错误。旧框架节点没有新契约时保留原行为。

## 执行与报告

执行阶段根据真实安装错误或缺失公开模块回溯恢复，保存每次容器、安装/执行阶段、退出码和锁摘要。环境与源码修复共用原节点最多 2 次修复预算。标准库及固定仓库模块不能用同名公开包替换；框架来源绑定的主包版本不能悄悄升级。

预检恢复的环境随回执进入正式运行；正式 Benchmark 的代码或环境变化必须在新容器重新通过最多 8 条样本后才可重跑全量数据。`preflight_rechecks`、`environment_changes` 和 `final_environment_lock` 保存该过程，安装失败的 `environment` 为 null，不能当作科研代码已经执行。

自动科研计划末尾的只读报告等待全部节点终止。初始准备失败时仍能把实际诊断返回聊天，原计划继续保持失败；成功后的汇总也包含准备阶段的失败/修复历史。缺少实际输出或指标，不能由报告生成来推断成功。

## 2026-10-20 验证

公开 PyPI 与真实 Docker 的两项用例通过（56.27 秒）：自动设计中的错误版本造成 uv 实际失败后修正并运行 PyYAML；显式 Requests 2.32.5 的不完整闭包补齐后实际安装并调用其请求准备 API。两条链均完成 8 条预检和 12 条全量预测，准确率为 1.0，仅为合成功能协议数据。设计、修复提议和报告措辞使用受控模型夹具；uv、PyPI、wheel 校验、安装、程序、预测及指标来自真实执行。

独立真实模型回执位于忽略目录 `.data/parity-live/initial-environment-67d3e3bd97374faab11193bce6b5d5a7/`。第一次 uv 实际冲突后，模型读取 PyPI 6.0.3 元数据，修正依赖并保留用户固定版本；计划 `47f7a0659e7b4538ab7c61853ab628c8` 完成，实际 Docker 输出 value=17、version=6.0.3、path=`/workspace/environment/yaml/__init__.py`。这是显式程序的环境恢复验收，不是任意论文的科学复现。
