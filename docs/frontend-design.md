# OpenResearch 科研工作台

面向论文复现与小型实验的本地工作台。2026-10-22 根据用户确认的交互，默认显示会话导航、科研对话、执行流程三列；选择步骤后，任务详情作为第四列展开，关闭后恢复三列。React 状态、身份、持久计划与 SSE 接口继续复用现有实现。

- 配色：画布 #f5f7f9、纸白 #ffffff、正文 #19232c、分隔 #e4e9ee、主色 #087f8c。失败和运行状态保留独立的语义颜色。
- 正文使用现有系统无衬线字体，提交、入口与参数使用等宽字体。
- 配置分为源码与环境、输入与预测、验收标准三个真实职责区；提交 SHA 与来源摘要是记录的一部分。
- 左侧会话可搜索和切换；身份配置收在工作空间入口。中间保留附件、推荐指令和 Markdown 对话；执行流程独立放在第三列，产物来自实际代码、节点报告与服务端文件记录。空会话保留流程栏，只显示等待计划的说明。
- 流程从上到下按依赖排列，同层并行节点并排，汇合及控制/数据边保持原有语义。长流程按栏宽缩放并纵向滚动，支持完整展开和缩放，不为塞进一屏而压小所有步骤。
- 桌面任务详情位于流程右侧，宽度可拖动或用分隔条上的左右方向键调整；至少保留约 320 像素对话宽度，流程宽度随详情展开收紧。报告、日志、代码、图表、证据图继续可用，报告/图表/证据图可全屏。
- PDF 在中间阅读，可全文翻译和划词追问；关闭回到原对话，切换研究会话时关闭上一份文档。高级实验配置继续使用独立表单，字段及提交协议保持兼容。
- 1024 像素及以上显示完整会话导航；更窄屏幕收为抽屉，任务详情作为右侧浮层。手机对话/流程使用页签，任务详情使用整宽视图。保持正文和输入框可达、无水平溢出、键盘焦点可见，并尊重减少动画偏好。
- 顶部仅保留品牌、实际服务连接状态和有效设置入口，移除“研”占位头像与重复的工作台标语。完成的流程不显示无效的运行按钮。
- 错误显示后端给出的具体原因；不预填研究结论或伪造运行结果。

顶部连接状态只检查实际 API `/ping`，不推断模型可用性。页面不写死设计图中的测试数量、耗时或 Python 版本。所有计划按钮继续调用原审批、执行、取消与重试接口。

通过概览或聊天打开报告时，流程图高亮与当前任务详情同步；关闭详情时清除高亮，避免停留在上一次鼠标选中的节点。
