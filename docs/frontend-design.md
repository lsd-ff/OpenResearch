# OpenResearch 科研工作台

面向论文复现与小型实验的本地工作台。2026-10-22 根据用户确认的设计稿，采用固定会话导航、中间对话与内嵌执行流程、右侧任务详情的三栏布局。React 状态、身份、持久计划与 SSE 接口继续复用现有实现。

- 配色：画布 #f5f7f9、纸白 #ffffff、正文 #19232c、分隔 #e4e9ee、主色 #087f8c。失败和运行状态保留独立的语义颜色。
- 正文使用现有系统无衬线字体，提交、入口与参数使用等宽字体。
- 配置分为源码与环境、输入与预测、验收标准三个真实职责区；提交 SHA 与来源摘要是记录的一部分。
- 左侧会话可搜索和切换；身份配置收在工作空间入口。中间保留附件、推荐指令和 Markdown 对话，流程支持完整展开、缩放和节点选择，产物来自实际代码、节点报告与服务端文件记录。
- 桌面任务详情与对话并排，宽度可拖动或用分隔条上的左右方向键调整；报告、日志、代码、图表、证据图继续可用，报告/图表/证据图可全屏。
- PDF 在中间阅读，可全文翻译和划词追问；关闭回到原对话，切换研究会话时关闭上一份文档。高级实验配置继续使用独立表单，字段及提交协议保持兼容。
- 窄屏会话导航收为抽屉；对话/流程使用页签，任务详情使用整宽视图。保持正文和输入框可达、无水平溢出、键盘焦点可见，并尊重减少动画偏好。
- 错误显示后端给出的具体原因；不预填研究结论或伪造运行结果。

顶部连接状态只检查实际 API `/ping`，不推断模型可用性。页面不写死设计图中的测试数量、耗时或 Python 版本。所有计划按钮继续调用原审批、执行、取消与重试接口。

节点面板的实时日志读取服务端持久事件。进入计划、刷新或切换回会话后，按当前身份绑定 Cookie，回放历史并继续接收 SSE；按事件序号去重，离开会话时关闭连接。回放中的旧失败不会截断后续重试记录，也不会重复追加聊天完成消息。报告正文继续以保存的节点结果为准，日志到达不能清空报告或用事件摘要覆盖完整正文。未产生结果时也可切到实时日志。实际恢复、断流及 Docker 执行验收见 [日志验证记录](execution-log-verification-2026-10-22.md)。
